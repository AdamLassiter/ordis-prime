# ADR 0004: Wiki is optional enrichment

Status: superseded in part by ADR 0055

Structured official and WFCD datasets form the catalog spine. The application
links to the Warframe Wiki for complete detail. ADR 0055 later introduced one
schema-specific automatic adapter for structured weapon modules.
Any future adapter must respect access policy and preserve licence/provenance at
fact level so its output can be disabled or removed independently.
