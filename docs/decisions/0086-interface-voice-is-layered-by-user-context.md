# 0086: Interface voice is layered by user context

Status: accepted

## Context

Ordis Prime should feel cohesive and recognisably connected to Warframe, but it
also exposes provenance, uncertain data and operational controls. Applying an
in-universe voice indiscriminately would make evidence harder to audit and
administrative actions harder to understand. Keeping every surface purely
technical would lose the product identity and make a player tool feel like an
internal database console.

## Decision

Use three copy layers: lightly diegetic outcome-led language for player
navigation, precise source-aware language for evidence and methodology, and
explicit technical language for administration and operations.

Use an original Cephalon-inspired voice rather than copied game dialogue.
Preserve official game terminology, accessible control labels and visible
uncertainty in every layer.

The shared visual system uses a restrained void, cyan and gold palette with
angular panels and signal cues. It must respect reduced-motion preferences and
must not depend on decorative imagery to convey state.

## Consequences

Player-facing screens can feel like connected Orbiter consoles without making
citations or failure states vague. Evidence and administration screens will be
less theatrical by design. New screens must choose their layer deliberately;
copying the landing-page tone into an import error or conflict review is a
design defect, not consistency.
