# Roadmap

## 1. Acquisition proof

Status: baseline implemented

Complete source snapshots, canonical promotion, linked item/node pages, local
accounts, inventory counts, goals, explainable node recommendations, and profile
export/import. This milestone proves that source data and personal state remain
separate while still producing useful joined answers.

## 2. Time-aware planning

Status: baseline implemented

Add world-state polling, availability windows, dynamic todos, in-app alerts,
then optional web-push and webhook delivery. Alerts are rules over canonical
entities and player goals, not provider-specific payloads.

Provider-neutral snapshots, current availability reads, automatic polling, the
public timer view, static todos, dynamic watches and in-app alerts are
implemented. Static todos support anchored calendar recurrence without
short-month drift. Optional external delivery channels remain.

## 3. Builds and opinions

Status: in progress

Add partial/full versioned loadouts and immutable share snapshots. Import cited
editorial rankings as independent observations and show disagreement before any
derived consensus.

Build drafts, editor/search workflow, class-checked arcanes, effect-selected
Archon Shard slots, immutable public snapshots and a source-faithful editorial
ranking comparison are implemented. Builds retain configuration labels, Forma
counts and capacity-upgrade state. Equipment slots and specialized weapon
arcanes enforce cited canonical classes. Calculated capacity/polarities,
structured modular-weapon parts, and richer ranking methodology remain. An
opt-in ordinal median/range summary is implemented with its assumptions visible.

## 4. Discovery and spatial navigation

Status: in progress

Model quests, mechanics, secrets and unlock prerequisites, then render the same
node graph as an interactive star chart. The map is a view over established IDs
and relations, not a second data model.

Composed node metadata, a planet-grouped chart with inventory-aware filtering,
a searchable canonical discovery atlas, and cited typed discovery relations are
implemented. Private discovery progress and filtering are also implemented.
Cited star-chart connection edges compose into node reads when supplied. Stable
coordinates, an attributed complete edge dataset, and richer quest-step progress remain.
